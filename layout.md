# InAmigos Foundation Awareness Website - Layout & Development Instructions

## 1. Project Overview
Create a visually engaging NGO awareness website for InAmigos Foundation that highlights its mission, projects, impact, and opportunities for public involvement. The website should be modern, interactive, emotionally engaging, and storytelling-focused rather than a simple informational page.

## 2. Design Requirements

### Theme
Create a vibrant and impactful NGO website with:
- Modern NGO-style design
- Emotional visual storytelling
- Smooth scrolling experience
- Rich animations & Hover interactions
- Parallax effects
- Horizontal scrolling sections & Vertical reveal animations
- Animated counters
- Floating decorative elements & Attractive gradients
- Glassmorphism cards where appropriate
- Responsive design for mobile and desktop

**Note:** Avoid minimalist designs. The website should feel dynamic and inspiring.

### Technologies
- HTML5
- CSS3
- Optional: Basic JavaScript for animations and counters
- **No frameworks required.**

### Color Palette
- **Primary:** `#0E7490`, `#16A34A`
- **Secondary:** `#F97316`, `#FBBF24`
- **Background:** `#F8FAFC`, `#FFFFFF`
- **Text:** `#1E293B`
